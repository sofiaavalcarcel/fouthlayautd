# Weekly Performance

Automatización concurrente de PageSpeed Insights para libros Excel. Valida la pestaña solicitada, toma URLs de D, escribe Desktop en L y Móvil en M, reintenta límites temporales y genera checkpoints recuperables.

La API vive bajo `/api/weekly-auto/performance` y la credencial opcional se obtiene exclusivamente de `PAGESPEED_API_KEY`.
