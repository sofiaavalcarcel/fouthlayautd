# Weekly Forms

Procesa la matriz QA directamente desde Excel, identifica formularios BLC y
landing pages por sus controles visibles, envía leads reales y verifica el
resultado en InConcert y/o Balanceador. Las filas con Lead existente se omiten;
las páginas sin formulario conservan Lead vacío para revisión manual.

El ritmo propio del módulo es fijo: cinco filas y una pausa de 60 segundos.
